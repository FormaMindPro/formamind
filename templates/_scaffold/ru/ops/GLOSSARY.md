# Глоссарий

Термины предметной области проекта — чем вещь *является*, одно-два предложения, без реализации (`AGENTS.md` §6). Записывается узлом `Intent`, как только термин выкристаллизовывается, а не пачкой. Для спорного слова выбирается одно, остальные помещаются в _Избегать_. Формат основан на [mattpocock/skills, `domain-modeling/CONTEXT-FORMAT.md`](https://github.com/mattpocock/skills/tree/main/skills/engineering/domain-modeling).

Формат строки:

```md
**Термин**:
Чем является, одно или два предложения.
_Избегать_: синоним, синоним
```

## Язык проекта

Пока терминов нет — первые появляются в ходе интервью и прояснения задач.
