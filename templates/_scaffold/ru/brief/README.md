# Бриф

Сказанное человеком до первой цели — фундамент, на котором стоит весь проект. Собирается с помощью техники интервью `grilling` под руководством узла `Intent` (`project/config/SETUP.md`, шаг 1).

## Файлы

| Файл | Что содержит |
|---|---|
| `idea.md` | замысел проекта: внешний вид, состав, общая цель, функции, маршрут, критерий готовности |
| `interview.md` | сценарий интервью: пять позиций (красота / простота / индивидуальность / честность-миссия / естественность) — не переписывается по ходу проекта |
| `history.md` | систематизированная запись сказанного человеком — все исходные параметры интервью в структурированном виде |
| `reference.md` | референсы, собранные на интервью и при уточнении брифа |
| `landing-prompt.md` | промпт первой страницы (лендинга) |
| `picture.md` | развёрнутая картина проекта |

**Не переписывается на ходу.** Бриф — снимок идеи на момент первого разговора (`AGENTS.md`, «Пять пар»: `project/brief` — опорная точка). Если образ результата разошёлся с брифом, расхождение называется открыто, а не замазывается здесь тихой правкой.
