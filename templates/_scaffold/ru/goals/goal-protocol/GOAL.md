# Главная цель вида `protocol` · Форма

Одна из девяти главных целей проекта — все девять ведутся параллельно (`intent-goal-opening.md`, «Эпик», «Как формируются цели»). Подцели — в карте `ROADMAP.md`, под этой целью.

---

**Вид**: `protocol` · дорожка доски — метка из `PROJECT.md`, «Эпики проекта».

**Метка карточек**: `goal-protocol`.

**Кем формируется**: ядром по умолчанию.

**Образ по умолчанию**: движок, собранный из имеющегося — знания, скиллы, плагины; настраивается по ходу движения.

**Образ в этом проекте**: движок, собранный из имеющегося — знания, скиллы, плагины; настраивается по ходу движения.

**Кто закрывает**: вердикт `Intent`; человек закрывает (запреты 1 и 8).
