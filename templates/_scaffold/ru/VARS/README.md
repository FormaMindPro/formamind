# Решённые значения проекта

То, что решено внутри работы и стало общим для всех целей: имя, цвет, формат, тон, адрес, единица измерения, тестовые учётные записи. Каждое значение живёт **здесь и только здесь**; цели и карточки ссылаются на него как `[[имя]]`.

Записывается узлом `Intent`, когда цель закрывается. Пересматривается человеком, как событие, а не правкой.

**`Kit` предлагает кандидатов на новое значение** — это главный практический пользователь `VARS/`: снаряжая задачи, он первым упирается в разрыв (`kit.md`, «Реквизиты доступа»). Предложение — строка в истории карточки, а не правка этого файла; решать и записывать по-прежнему только `Intent`, при закрытии цели.

**Это папка, а не один файл.** Список значений разного рода — числа дизайн-системы, тестовые пользователи, адреса — не обязан жить в одной таблице. Каждый файл `VARS/<сущность>.md` — одна такая таблица по своей теме, в том же формате, что ниже. Этот файл (`VARS/README.md`) содержит только метод: как называть, как пересматривать. Заведение новой сущности значений — новый файл `VARS/<имя>.md`, строка ссылки на него здесь, в списке ниже.

## Пересмотр

Изменение решённого значения — **не правка, а событие**. Причина обычно одна: среда не даёт того, что было записано — `Spec` остановился и доложил.

Порядок:

1. **Собрать, что затронуто** — по колонке «Опирается» и поиском `[[имя]]`. Список получается механически, не по памяти — для этого колонка и ведётся.
2. **Решить, что делать с каждой затронутой целью:** пересмотреть, оставить, переоткрыть. Закрытые цели, переставшие быть правдой, возвращаются в `ROADMAP.md`, в состояние `open`.
3. **Записать новое значение сюда** и изменение в `JOURNAL.md`, раздел «Изменено в инфраструктуре»: что было, что стало, почему, кто решил.
4. **Справочники, где это значение названо, получают новую версию.** Макет, дизайн-система. Старая версия остаётся.
5. **То, что сделано по старому значению, помечается** — в эталоне состава, где ведётся состав вещи.
6. **Помеченное исправляется задачами оснастки следующего круга**, а не переделыванием текущего. Иначе круг никогда не закроется.

**Волна не идёт назад по закрытым кругам.** Закрытая папка не переписывается: расхождение выносится вперёд задачами, и оно видимо. Переписанное задним числом видимо не будет.

Без первого шага значение меняется молча, и через три цели половина проекта держится на том, чего больше нет.

## Колонка «Опирается»

Заполняется **именами того, что сломается**: страницы, разделы макета, справочники. Не номерами целей — по номеру цели не найти, что чинить.

Пустая колонка делает пересмотр невозможным: значение изменить можно, а последствия узнать нельзя.
