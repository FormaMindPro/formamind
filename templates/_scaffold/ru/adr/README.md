# Журнал решений (ADR)

Постоянная запись принятых решений проекта (`AGENTS.md` §6).

**Когда создаётся — три условия одновременно:**
1. **Трудно отменить** — изменить решение позже будет дорого.
2. **Удивляет без контекста** — будущий читатель спросит: «почему именно так?».
3. **Итог реального выбора** — были подлинные альтернативы, одна выбрана с обоснованием.

Если хотя бы одно условие отсутствует — ADR не создаётся: решение остаётся в карточке.

**Кто пишет:** `Intent` при подтверждении закрытой карточки вида `decision`. Карточка держит основание, ADR держит постоянную запись.

**Нумерация:** максимальный номер в папке + 1: `0001-<slug>.md`.

## Шаблон

```md
# {Краткое название решения}

{1–3 предложения: контекст, что решено и почему.}

Источник: card-NNN.
```
