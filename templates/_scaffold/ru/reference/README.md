# Справочные материалы

Справочные материалы проекта — дизайн-система, спецификации сущностей, промпты, исходные каталоги и тому подобное, на что ссылаются карточки задач. Содержимое целиком зависит от проекта: схема протокола его не диктует, эта папка — выделенное место, чтобы такие материалы не расползались по корню.

Создаётся по ходу дела — по мере появления в проекте того, на что нужно ссылаться многократно.

Не путать с `project/VARS/` — там живут осевшие единичные значения, здесь — развёрнутые материалы (документы, каталоги, эталоны).
