# project/extensions/

То, что этот проект надстраивает поверх протокола: собственные роли, скиллы, скрипты и хуки. Является источником правды и переживает переустановку протокола.

```
extensions/claude/   -> .claude/    (agents/run/*.md, scripts/, skills/, hooks/)
extensions/codex/    -> .codex/
extensions/agents/   -> .agents/
```

- Новые наработки пишутся сюда, а не напрямую в папки движков. В папках движков лежат копии, синхронизируемые скриптом `node .forma/extensions/extensions.cjs`.
- Файл здесь с тем же именем, что и файл движка, заменяет его; синхронизация выводит `override`.
- Ручная правка копии сохраняется и выводится как `drift`; правку следует переносить сюда.
