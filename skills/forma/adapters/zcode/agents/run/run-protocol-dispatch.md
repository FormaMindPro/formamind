# `run-protocol-dispatch`

Profile of `run.md` for one kind of work — the base role's criteria and process apply; this file only narrows the kit.

## When to take

A tooling card whose result is the dispatcher channel from a card to a run on its model through a ZCode workflow subagent: the address resolver (`dispatch-address.cjs`) from the card's `Model` kit unit — or, when that unit is empty, from the node default declared in `PROJECT.md` — to a `providerId/modelId` address, validated against a saved `ListModels` snapshot and refused fail-closed (exit 2, address and source named, no spec printed) on an absent snapshot, an unknown address or no address at all; the printed `CreateWorkflow` spec (`name`, `subagent_model`, the script carrying the node's prompt from `dispatch-prompt.cjs`), with `--probe` printing the same spec whose task is "return the marker, do nothing"; the workflow-actor transcript locator that turns a `dwfrun-*` run id into the §3 spend line through `subagent-spend.cjs`/`card-subagent-spend.cjs`; and the contract next to "the dispatcher decides nothing" in `route-choice.md`, its copy carried into the protocol template. Verified by the resolver's `--self-test` (card path, `PROJECT.md` default path, unknown address, absent address, absent snapshot), the zcode adapter test, the engine check, `sync-engines --check` and the English-code gate.

## Takes / does not take

- **Takes:** «add `dispatch-address.cjs`: read a card's `Model` unit, fall back to the node default in `PROJECT.md`, resolve a bare model name only inside the session's provider, validate against a `ListModels` snapshot, refuse fail-closed with exit 2 above a printed spec, `--probe` for the marker-only spec»; «teach the zcode adapter to find the actor transcript `model-io-sess_dwf-<run>-actor_N_M.jsonl` by `dwfrun-*` id so `card-subagent-spend` writes the actor's §3 line, an absent file staying `unknown`»; «write the dispatcher contract into `route-choice.md` beside "the dispatcher decides nothing" and carry it to the protocol template, the zcode copy regenerated, all gates green».
- **Does not take:** «edit an existing protocol Node script that has no host-workflow semantics — a graph builder, a board script, a parser» (→ `run-protocol-script`); «change the Plumb driver or its scrub» (→ `run-protocol-driver`); «run an already-written script and report its output» (→ `run-script`); «text-only edit of protocol markdown with no code and no host contract» (→ `run-protocol-docs`); «launch the workflow, approve it on the human's behalf or write the live actor's spend line» — `CreateWorkflow` is a host session tool that a subagent does not hold: the live run and its approval are the session's, and this role stops at the printed spec plus its fixture verification.

## Boundary

- **The script prints; the session launches.** The printed spec is the deliverable boundary: no `CreateWorkflow` call from this role, no live snapshot from it either (`ListModels` is a host session tool that a subagent does not hold). Build and verify against fixtures; the live run, the human's approval on it and the actor's §3 line in `## History` are the session's step after the card returns.
- **Fail-closed is the whole point.** With no snapshot, an address absent from the snapshot, or no address in the card and no default declared in `PROJECT.md`, the resolver writes the refusal on stderr, names the address (or `(none)`) and its source, exits 2, and prints no spec on stdout. A silent fallback to a nearby model, to the session model or to the adapter's `nodeModels` table is a substitution, not a convenience.
- **The default is declared, not inferred.** The node default lives in `PROJECT.md`, «Оснастка узлов», the node's row, written there by the human; the engine adapter's `nodeModels` table is the engine's own bookkeeping and is never read as the address. A project that declares no default makes the default path refuse — that is correct behavior, and the self-test proves it on a fixture `PROJECT.md`.
- **The marker has no default.** `dispatch-prompt.cjs` refuses a build without `--marker` (law §4); the spec command passes the marker explicitly, and `--probe` replaces the task text with the marker-only one.
- **Transcript absence is `unknown`, never zero.** The locator resolves `model-io-sess_dwf-<run>-actor_<N>_<M>.jsonl` in the adapter's `transcriptsDir`; several actors under one run id — the caller names the actor, the locator lists the candidates rather than picking silently. A missing file prints the `unknown` markers with the reason, exactly as `subagent-spend.cjs` already does.
- **Files in scope:** the new `.claude/scripts/dispatch-address.cjs`; the locator in `.zcode/forma-adapter.cjs` and, only if it must learn the id shape, the spend reader next to it (`subagent-spend.cjs`, `card-subagent-spend.cjs`, `.forma/dashboard/subagent-transcript.cjs`); `.zcode/tests/test-zcode-adapter.cjs` for the locator; `.claude/agents/on-demand/route-choice.md`, with `.zcode/agents/on-demand/route-choice.md` regenerated by `gen-roles.cjs`, never by hand. The template copy goes by `engine-to-protocol.cjs`: list first, then `--add` (one path per flag) for the new script and `--apply` only for the named edited files; a "both changed" conflict is a stop and a return to `Kit`, not a resolution on the spot. Commit in the protocol clone without push, English message (prohibition 18).
- **Clean and ASCII.** The new script and its tests carry no card codes, dates, hosts or project names (prohibition 16) and no Cyrillic (prohibition 19); credentials are neither read nor written (prohibition 15). Fixtures and temp output go to the project's resolved temp base (`FORMA_TEST_TMP`, then the RAM disk, else `os.tmpdir()`), never into the repository.
- **Verify by the command's own last line,** not by "green": the resolver's self-test covers every refusal and both source paths; the card's gates are run as given. A second identical diagnosis (prohibition 14) is a stop.
